# DevMantra SyncPlay

🎬 DevMantra SyncPlay is an open-source real-time Watch Together platform built for seamless online viewing experiences.

Create a private room, invite friends, and enjoy synchronized playback with ultra-low latency.

## Features

- 🎥 YouTube synchronized playback
- 📁 Local video synchronization (each participant uses their own local file)
- 💬 Real-time chat
- 🎙 Voice chat
- 📹 Video calling
- ⚡ Instant play/pause/seek synchronization
- 👥 Private rooms
- 🔗 Shareable invite links
- 😊 Emoji reactions
- 🌙 Modern dark UI
- 📱 Responsive design
- 🔒 Secure room management
- 🚀 Open Source

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Node.js
- Express
- Socket.IO
- WebRTC
- PostgreSQL / Supabase
